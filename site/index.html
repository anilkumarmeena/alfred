Your own voice assistant, on your computer

Alfred listens, thinks and speaks on your machine. Speech stays on-device, Claude does the thinking, and it gets real work done while you talk, from your terminal, browser or phone.

Safety

Guards in code, not in the prompt

Spoken yesMail, invites and deletions wait for a clear yes
ApprovalsInstalls, pushes and data leaving the computer wait for you
Auto modeEvery action checked; anything beyond what you asked is blocked or waits for you
Encrypted vaultKeys are encrypted and never spoken
Injection checksMail, pages and tool results screened
Local onlyYour phone reaches it privately over Tailscale

Install

Talking in three steps

1

Install

git clone https://github.com/anilkumarmeena/alfred.git
cd alfred && make install
2

Set up

make claude-status
make setup
3

Talk

make console

You need uv, Node.js 22+ and the Claude Code CLI with a Claude account. Full setup guide
